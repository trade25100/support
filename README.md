# Support Tracker V4 — GitHub Pages

Un seul site pour 12 supports, avec un profil indépendant pour chaque héros.

## Installation
1. Décompresser le ZIP.
2. Mettre `index.html` à la racine du dépôt GitHub.
3. Activer Settings > Pages > Deploy from a branch > main / (root).
4. Ouvrir le lien GitHub Pages. Aucune installation ni serveur requis.

## Utilisation
- Sélectionner un héros dans « Choisir ton support ».
- Les 26 matchs du fichier fourni sont préchargés dans Mercy uniquement, si aucun ancien stockage V4 n'existe.
- Chaque héros a ses matchs, SR, objectifs, maps, galeries et notes séparés.
- « Exporter JSON » sauvegarde tous les héros en un seul fichier.
- « Importer JSON » accepte un export V4 complet ou une sauvegarde V1/V3 dans le héros sélectionné.
- Le premier chargement peut reprendre une ancienne sauvegarde Mercy du même navigateur (`mercy-tracker-v2`).
- Les données sont stockées localement dans le navigateur. Exportez régulièrement.
- Pour un nouveau support, le SR initial est 1500 par défaut et peut être modifié. Ce n'est pas une valeur de rang officiel.

Site non officiel, sans connexion à Blizzard.
